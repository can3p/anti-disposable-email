# Data sources

`disposable.txt`, `relay.txt` and `allowlist.txt` are generated by
`go run ./cmd/update-lists`. Do not edit them by hand: add overrides to
`allowlist_local.txt` instead.

| File | Built from |
|---|---|
| `disposable.txt` | Union of all blocklists below, minus `allowlist.txt` and `relay.txt` |
| `relay.txt` | disposable/disposable `domains_forwarding.txt` minus its `domains.txt`, minus `allowlist.txt` |
| `allowlist.txt` | disposable/disposable `whitelist.txt` plus `allowlist_local.txt` |
